# Premium Graphic Designer Portfolio

A luxurious, dark-themed personal portfolio website for Graphic Designers, built with Flutter. Inspired by Awwwards, Framer, and Behance.

## Features
* Modern dark theme (#0B1220) with blue accents (#3B82F6)
* Glassmorphism cards and clean UI
* Fully responsive layout (Mobile, Tablet, Desktop)
* Animated progress bars for skills (Planned)
* Masonry grid for featured portfolio projects (Planned)
* Smooth scrolling and hover effects

## Getting Started

1. Ensure you have Flutter installed (version 3.7.2 or higher).
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to launch the app on your preferred device.
